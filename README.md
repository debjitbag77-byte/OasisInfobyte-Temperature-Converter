# OASIS INFOBYTE — Task 3: Temperature Converter

**Debjit Bag · B.TECH in CSE**

A responsive temperature conversion utility built with HTML5, CSS3 and Vanilla JavaScript.

## Features
- Celsius, Fahrenheit and Kelvin
- Numeric input validation
- Absolute-zero validation
- Conversion button
- All three results shown simultaneously
- Responsive centered interface
- No frameworks or build tools

## Run
Open `index.html` in a modern browser.

## Formulas
- °F = (°C × 9/5) + 32
- K = °C + 273.15
- °C = (°F − 32) × 5/9
